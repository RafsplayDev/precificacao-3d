Catalogue tile for a printed product sold direct to the customer.

```jsx
<ProductCard name="Vaso Onda" price="R$ 89" note="PLA · 18 cm · 3 dias" badge="Novo"
  colors={FILAMENTS.slice(0,5)} color={cor} onColorChange={setCor} />
```

Media block uses the print-bed grid (`dc-bedgrid`) when there is no photo.
