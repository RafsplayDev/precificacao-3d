The standard Drop Color action control — pill-shaped, ink by default.

```jsx
<Button variant="accent" size="lg" iconRight={<Icon name="arrow-right" size={18} />}>Montar meu kit</Button>
<Button variant="secondary">Ver detalhes</Button>
```

Use exactly one `accent` (magenta) button per view; everything else is `primary`, `secondary` or `ghost`. `inverse` is for dark sections.
