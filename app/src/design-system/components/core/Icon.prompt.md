Renders a Lucide glyph; the only icon primitive in Drop Color — never hand-roll an SVG path.

```jsx
<Icon name="shopping-bag" size={18} />
<Icon name="arrow-right" size={22} strokeWidth={2} color="var(--fil-magenta)" />
```

Requires the Lucide UMD build on the page: `<script src="https://unpkg.com/lucide@0.474.0/dist/umd/lucide.js"></script>`.
Brand stroke weight is 1.75 at 18–22px; go to 2 only below 16px.
